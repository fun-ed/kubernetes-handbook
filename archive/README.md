# 历史归档

本目录保存从当前版移出的旧教程、清单和主机服务配置，也保存已被新指南取代的历史原文，供查阅旧架构、识别迁移风险和追溯原始内容。归档中的命令与资源不能作为 Kubernetes v1.36 或 v1.37 的部署说明。本仓库的目标版本为 Kubernetes v1.37.1。

## 归档范围与判定标准

归档仅涵盖符合以下条件的内容：

- 上游明确将 API、组件或项目标记为已移除、弃用、归档、停止维护或退役，且原示例不能用于当前部署。
- 教程固定使用较早 Kubernetes 版本、已更换的安装机制、已失效的 API 或已停止维护的组件，照原步骤不能用于 v1.36/v1.37。
- 历史清单仍可能被误当作当前资源应用，或旧主机服务配置不属于当前节点部署路径。

没有找到当前兼容性声明，不等同于已证明不兼容或项目已退役。Romana、OpenContrail 等生命周期尚未证实的内容仍保留在当前目录，并明确说明兼容性尚未核实。仍可用于解释当前概念的混合章节也保留在当前版本；仅当旧 API、安装步骤或资源可明确分离时，才单独归档这些部分。

归档文件保留原目录层级、正文、现存的 `HISTORICAL` 标记和相关引用。文档中的相对链接和图片路径已按归档位置调整。`index.md` 按原路径逐项列出归档位置和判定依据，并单独标出原内容已封存、原路径已改写为当前指南的页面。

## 如何浏览

本目录通过 GitHub 源码提供独立导航：从本页进入[归档索引](index.md)，再按原路径打开文件。根目录的 `.bookignore` 将 `archive/` 排除在当前 HonKit 书籍之外，因此归档不会混入当前版目录、生成的站点或当前清单验证范围。

当前 Kubernetes 部署入口见[集群搭建指南](../setup/index.md)。归档文件不是当前指南的替代品，也不表示其中每个命令都已逐项复现或验证。

部分页面在原路径提供经改写的现行指南，旧版原文另存于本目录。请查看索引中的“原内容封存、现行页面重写”表；这些现行页面仍属于当前内容，不是从当前版移除的页面。当前页面链接到归档的 GitHub 源码，归档文件不纳入 HonKit 构建或当前清单验证。
