# 历史归档索引

此索引列出从 Kubernetes v1.36/v1.37 当前版导航移出的教程和资源，逐项记录原路径、归档路径及判定依据。文件按原目录层级保存在归档中；其中的命令和清单仅供历史参考，不是当前部署说明。

索引中的逐项判定依据保留英文，以便对应原文和其中的版本、API、项目状态等证据；下方分类标题和说明用于概括各组内容。兼容性声明缺失本身不构成退役或不兼容的证明，详见[归档说明](README.md)。

本目录作为 GitHub 源码中的独立索引浏览，不属于当前 HonKit 书籍；根目录 `.bookignore` 会排除归档内容。
