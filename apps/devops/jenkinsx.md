# Jenkins X

[Jenkins X](https://jenkins-x.io/) 是面向 Kubernetes 的 CI/CD 项目。其架构、发行版与安装流程已不同于本页旧版 Jenkins X 1.x 教程；不要在新集群运行旧 `jx install`、旧集群创建命令或其示例发布操作。

本页不提供未经上游当前文档核实的安装配方。选择 Jenkins X 发行版前，请从[官方文档](https://jenkins-x.io/)确认该发行版的维护状态、安装方式、Kubernetes 支持范围和升级路径，并在隔离环境验证权限、Git 平台集成、构建器及制品仓库配置。本次未核实到 Jenkins X v1.37 支持声明，不代表已证实兼容或不兼容。

旧版安装与应用发布教程已移至[历史归档](https://github.com/fun-ed/kubernetes-handbook/blob/main/archive/apps/devops/jenkinsx.md)，仅供理解旧工作流，不是当前产品说明。
