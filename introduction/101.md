# First application with Kubernetes

This walkthrough creates a small Deployment, checks its rollout, and forwards a local port. The NGINX image tag `1.30.5` was verified as the stable release on 2026-10-05; use the image approved by your own release and security process in production.

```bash
kubectl create deployment nginx-app --image=nginx:1.30.5
kubectl rollout status deployment/nginx-app
kubectl get deployment,pods -l app=nginx-app
```

Inspect logs and verify the HTTP response through a local port-forward:

```bash
kubectl logs deployment/nginx-app
kubectl port-forward deployment/nginx-app 8080:80
```

In another terminal, request `http://127.0.0.1:8080`. Stop port-forwarding with Ctrl-C when finished. The port-forward is local to the machine running `kubectl`; it is not an externally published Service.

The Deployment manages the Pod and can replace it when a Pod or Node fails. The Pod name, address and node are transient; query the current resources rather than copying old Pod identifiers or IP addresses from a transcript. Use `kubectl delete deployment nginx-app` to remove the example workload after confirming the target cluster and namespace.
