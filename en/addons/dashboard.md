# Kubernetes Dashboard status

**The upstream Kubernetes Dashboard project was archived on 2026-01-21** under the `kubernetes-retired` GitHub organization. It is not a maintained UI to install on a new Kubernetes v1.37 cluster. See the [archived repository](https://github.com/kubernetes-retired/dashboard). This page intentionally contains no old manifest, Helm, or static ServiceAccount-token deployment commands.

If you need a Kubernetes UI, evaluate the maintained [Headlamp](https://headlamp.dev/) project and follow its current installation, authentication, authorization, and Kubernetes compatibility guidance. Do not expose a cluster administration UI publicly without strong authentication and least-privilege access.

> **Historical note:** the old v1.10.1 manifest in this page described an early preview installation. It is not applicable to Kubernetes v1.37.1.
