# Kubernetes Handbook (English pages)

This repository is primarily maintained in Chinese. The English directory is an incomplete collection of translated and older reference pages, not a complete English edition of the current Kubernetes v1.37.1 handbook. Historical and troubleshooting pages can contain examples for retired APIs and runtimes; use only instructions explicitly identified as current.

For the current Kubernetes v1.37.1 route, use the Chinese maintained pages:

- [Version and component baseline](../setup/index.md)
- [Create a Linux cluster with kubeadm](../setup/cluster/kubeadm.md)
- [Kubernetes v1.37 migration notes](../setup/kubernetes-v1.37.md)
- [Version skew and upgrade order](../setup/upgrade.md)
- [Component versions and upstream compatibility evidence](../setup/component-versions.md)

English addon pages state their current status individually. Do not apply old manifests, package repository URLs, provider commands, or API examples merely because they appear in this partial translation.
