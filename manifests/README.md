# Manifest status and Kubernetes compatibility

This directory contains manifests for individual resources and small examples. Do **not** recursively apply `manifests/` or a directory with unrelated resources. Review prerequisites and apply only the files selected for your cluster.

The target baseline is Kubernetes v1.37.1. A current API schema or image tag does not by itself prove that a controller or addon supports Kubernetes 1.37. Check the linked upstream compatibility guidance before production use. The pinned project releases and source evidence are collected in [`setup/component-versions.md`](../setup/component-versions.md).

## Historical resources

Retired component manifests, obsolete API examples, and standalone files marked `HISTORICAL:` have been moved under `archive/manifests/`, preserving their subdirectories. They are excluded from the current `examples/` and `manifests/` validation roots and should not be used as Kubernetes v1.36/v1.37 installation resources.

The [archive index](https://github.com/fun-ed/kubernetes-handbook/blob/main/archive/index.md) lists each old path and its replacement path with evidence. Current resources remain in this directory, including the kubeadm-derived CoreDNS example and the cert-manager ClusterIssuer example, whose Kubernetes v1.37 support remains unverified.
