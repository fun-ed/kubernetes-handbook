# 如何貢獻

1. 在 Github 上 [Fork](https://github.com/fun-ed/kubernetes-handbook/fork) 專案到自己的儲存庫。
2. 將 fork 後的專案拉到本地: `git clone https://github.com/<user-name>/kubernetes-handbook`。
3. 新建一個分支，並新增或編輯內容：`git checkout -b new-branch`。
4. 提交並推送到 GitHub：`git commit -am "comments"; git push`。
5. 在 GitHub 上提交 Pull Request。
