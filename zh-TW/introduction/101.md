# 在 Kubernetes 執行第一個應用程式

本教學會建立小型 Deployment、檢查 rollout，並轉送本機連接埠。NGINX 映像檔標籤 `1.30.5` 已於 2026-10-05 驗證為穩定版本；正式環境請使用組織核准的映像檔及發布與安全政策。

```bash
kubectl create deployment nginx-app --image=nginx:1.30.5
kubectl rollout status deployment/nginx-app
kubectl get deployment,pods -l app=nginx-app
```

檢查記錄並透過本機連接埠轉送確認 HTTP 回應：

```bash
kubectl logs deployment/nginx-app
kubectl port-forward deployment/nginx-app 8080:80
```

在另一個終端機請求 `http://127.0.0.1:8080`。完成後按 Ctrl-C 停止 port-forward。這個連接埠轉送只會監聽執行 `kubectl` 的本機，不會對外發布 Service。

Deployment 會管理 Pod，並能在 Pod 或 Node 故障時替換 Pod。Pod 名稱、位址和節點都是暫時性的；請查詢目前資源，不要照抄舊 transcript 的 Pod ID 或 IP 位址。確認目標叢集及命名空間後，可用 `kubectl delete deployment nginx-app` 移除此範例工作負載。

舊版教學的命令輸出是 Kubernetes v1.3 時期的歷史 transcript，已保存在[歷史歸檔](https://github.com/fun-ed/kubernetes-handbook/blob/main/archive/introduction/101-legacy-transcript-zh-TW.md)；其中的識別碼與命令都不是目前操作指引。
