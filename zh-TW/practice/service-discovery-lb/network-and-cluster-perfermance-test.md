# Kubernetes 網路和叢集效能測試

> **歷史基準，不代表當前效能**：本頁原始結果來自舊版 Kubernetes、Traefik 和測試環境，缺少可復現的叢集版本、CNI、硬體、負載與統計方法。文中毫秒數不能作為 v1.37、CNI、雲平台或生產容量規劃的基準。請按當前環境重新執行測試並記錄完整拓撲與工具版本。

## 復現前需要固定的條件

本文的歷史步驟與數字保留為早期測試記錄，不應用於證明當前產品效能。重新測試時至少記錄 Kubernetes 與 runtime 版本、節點和網路硬體、CNI 與 kube-proxy backend、Ingress/Gateway 實現、工作負載映像檔 digest、並行模型、請求數量、預熱與重複次數。

關注分位數、吞吐、錯誤率與資源用量，而不是單次平均響應時間。使用對照組區分 Pod-to-Pod、ClusterIP、外部 LoadBalancer/Ingress 路徑，並在代表性生產拓撲中壓測。測試系統應有容量邊界與停止條件，避免對共享叢集造成影響。

原文中的 IP、舊 Traefik/Ingress 路徑及數值只用於識別原始實驗資料；不要把這些端點或結果複製到新叢集。
