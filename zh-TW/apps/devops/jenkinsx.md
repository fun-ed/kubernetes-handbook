# Jenkins X

[Jenkins X](https://jenkins-x.io/) 是面向 Kubernetes 的 CI/CD 專案。其架構、發行版與安裝流程已不同於本頁舊版 Jenkins X 1.x 教學；請勿在新叢集執行舊版 `jx install`、舊叢集建立命令或其範例發布操作。

本頁不提供未經上游目前文件核實的安裝配方。選擇 Jenkins X 發行版前，請從[官方文件](https://jenkins-x.io/)確認該發行版的維護狀態、安裝方式、Kubernetes 支援範圍和升級路徑，並在隔離環境驗證權限、Git 平台整合、建置器及成品儲存庫設定。本次未核實到 Jenkins X 支援 v1.37 的聲明，不代表已證實相容或不相容。

舊版安裝與應用程式發布教學已移至[歷史封存](https://github.com/fun-ed/kubernetes-handbook/blob/main/archive/zh-TW/apps/devops/jenkinsx.md)，僅供了解舊工作流程，並非目前產品說明。
